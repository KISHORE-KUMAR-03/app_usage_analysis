📊 Mobile App Usage Analysis

🔍 Project Overview
This project analyzes mobile application usage data to understand user behavior, engagement, and feature popularity.
 🛠 Tools Used
- SQL (SQLite)
- Power BI
- Excel
📂 Dataset
The dataset contains the following columns:
- user_id
- usage_date
- session_time
- screen
- app_version
- day_type (Weekday / Weekend)
 📈 Key Insights
- Total number of unique users
- Average session time across users
- Most frequently used app screens
- Comparison of user activity on weekdays vs weekends
 📊 Dashboard Features
- KPI cards for Total Users and Average Session Time
- Bar chart showing Most Used Screens
- Column chart comparing Weekday vs Weekend usage
 🧠 Business Impact
This analysis helps product teams:
- Identify highly engaging features
- Optimize app design based on usage patterns
- Plan feature releases during high engagement periods
